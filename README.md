# 🌌 우리은하 실험실

중학교 3학년 과학 「별과 우주」 — **우리은하의 모양·크기·구성 천체**.
성취기준 **[9과23-02]**, 소단원 **(3) 우리가 살고 있는 은하**

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 🌌 실험실 | `index.html` | 우리은하를 위/옆에서 보고, 은하수가 왜 띠인지 확인한다 |
| 📝 학습지 | `worksheet.html` | 25문항 (20문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🗂️ 선생님용 | `teacher.html` | 제출한 PDF 를 파일 이름만 읽어 정리한다 |

## 무엇을 보여 주나

- **🌌 우리은하의 모양** — **위에서** 보면 막대 모양 중심부와 나선팔, **옆에서** 보면 볼록한 원반.
  태양계가 중심에서 8500 pc 떨어진 곳에 있다는 것도 함께 봅니다.
- **🥛 은하수** — 원반 안에서 시선을 이리저리 돌려 봅니다.
  시선이 원반을 **길게 지날수록** 별이 겹쳐 밝아요.
- **✨ 성단과 성운** — 산개 ↔ 구상, 방출 ↔ 반사 ↔ 암흑을 **나란히** 놓고 비교합니다.

## 이 앱이 남기고 싶은 한 문장

> **우리가 원반 안에 있기 때문에 은하수가 띠로 보인다.**
> 같은 이유로 중심 쪽이 더 밝고 두껍고, 밤하늘이 중심을 향하는 여름에 잘 보인다.

학습지의 물음 세 가지가 모두 이 하나에서 풀립니다.

## 미션 6개

1. 🌌 우리은하는 무슨 모양? · 2. 📍 태양계는 어디에? · 3. 🥛 은하수는 왜 띠일까
4. 🔭 폭과 밝기는 일정할까 · 5. ☀️ 왜 여름에 잘 보일까 · 6. ✨ 성단과 성운 짝 맞추기
